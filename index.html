에어드롭 가이드

뱃지 읽는 법부터

🏷 뱃지 읽는 법

  • 카테고리 — 참여 방식. 무료는 지갑 연결·퀘스트만, 테스트넷은 가스비 0원 연습망, 대기자는 이메일/소셜 웨이트리스트, 소셜 미션은 팔로우·리트윗, 거래/스테이킹은 실제 자금 필요, 이벤트는 경쟁·추첨, 노드는 서버 운영.
  • 무료 가스비 입금 선택 입금 필요 — 돈이 드는지. 입금 필요는 원금이 들어가는 항목이니 공식 규정부터 확인.
  • 참여 설명 버튼을 누르면 단계별 참여 방법과 주의사항이 뜬다. 바로가기는 원문 페이지.

🛠 사전 준비

  1. MetaMask + Phantom 설치
  2. ETH/SOL 소량 ($5~20 가스비)
  3. Chainlist에서 Base/Arb/OP RPC 추가
  4. 에어드롭 전용 지갑 따로 생성
  5. X, Discord, Telegram 계정

🧪 테스트넷 (가스비 0원)

  1. 테스트넷 사이트 접속
  2. Faucet에서 테스트 토큰
  3. 스왑/브릿지/스테이킹 테스트
  4. 피드백 (Discord)
  5. 주 2~3회 꾸준히

고정 추천 목록은 몇 달이면 낡는다(테스트넷이 메인넷으로 넘어가 버린다). 지금 도는 테스트넷은 에어드롭 탭의 테스트넷 뱃지로 확인해라.

⚠️ 주의

  • 시드구문·개인키 입력 = 스캠 100%
  • Revoke.cash로 어프루벌 해지
  • 에어드롭 전용 지갑 사용
  • 시빌 = 차단
  • "입금하면 에어드롭" = 스캠
